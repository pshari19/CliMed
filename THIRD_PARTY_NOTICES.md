# Third-party components

The build environment uses third-party Python packages including PyQt6, NumPy, pandas, xarray, SciPy, Matplotlib, Rasterio, GeoPandas, Shapely, pyproj, Pyogrio, netCDF4, HDF5-related packages, Cryptography and Nuitka.

Before the GitHub release, generate a package/version/licence inventory from the exact Windows build environment and retain the corresponding licence notices required by those packages. Do not infer the final third-party licence inventory from this source folder alone because installed versions may differ.
