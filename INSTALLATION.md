# Installation and use

## Windows release

1. Open the repository's **Releases** page.
2. Download the current CliMed Runs 1–3 Windows release package when available.
3. Keep the supplied `license.lic` in the location specified by the release package.
4. Start CliMed.
5. Select the required climate input, AOI boundary, LULC and population input.
6. Run Step 1, then Step 2, then Step 3.

## Test data

The repository includes example climate, India Admin2 boundary and India LULC files under `data/`. These files are intended only to support a reproducible software test.

Population, VIIRS/night-light and Aedes occurrence/suitability data are not bundled and must be supplied by the user when required.

## Input details

See `DATA_REQUIREMENTS.md` and `DATA_PROVENANCE.md` before using the example data or preparing substantive analyses.
