# Changelog

## v1.0.0 public release candidate — 20 August 2026

- Public Runs 1–3 release prepared for Windows distribution.
- Supports climate-input preparation, common-grid processing and mechanistic Aedes transmission calculations.
- Supports *Aedes aegypti*, *Aedes albopictus* and weighted combined-species modes.
- Public model-derived outputs include EIR, force of infection, infection probability, vector-to-host ratio and infectious-vector fraction.
- Population remains user-supplied as a raster or numeric density value.
- VIIRS/night-light and Aedes occurrence/suitability data remain optional user-supplied inputs and are not bundled.
- Added approved example climate, administrative-boundary and LULC test data.
- Public runtime licence is signed and valid through 31 December 2030 UTC.
